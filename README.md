# Knowledge Vault

**English:** Personal knowledge base with folders, Markdown preview ([marked](https://marked.js.org/) CDN), tag cloud, pinned favorites, full-text search with highlight, reading mode, JSON import/export, and `j`/`k` keyboard navigation. Elegant dark reading UI; data in `localStorage`.

**Español:** Base de conocimiento: carpetas, vista previa Markdown, nube de etiquetas, favoritos, búsqueda con resaltado, modo lectura, importar/exportar JSON y navegación con teclado. Interfaz oscura para lectura.

## Features / Características

- Live Markdown preview / Vista previa en tiempo real
- Tag cloud filter & folder sidebar / Etiquetas y carpetas
- Pin favorites / Notas fijadas
- Search highlight in list and preview / Resaltado de búsqueda
- Reading mode (`R`) / Modo lectura
- Export all notes JSON & import backup / Respaldo JSON
- Keyboard: `J` next note, `K` previous / Atajos j/k
