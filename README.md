# Knowledge Vault

**English:** Personal knowledge base with folders, Markdown notes, tags, and full-text search. Dark reading-focused UI; data stored in `localStorage`.

**Español:** Base de conocimiento personal: carpetas, notas Markdown, etiquetas y búsqueda. Interfaz oscura para lectura; datos en el navegador.

## Demo

https://julianaastudillo08.github.io/knowledge-vault/

## Local use

Open `index.html` in your browser.
